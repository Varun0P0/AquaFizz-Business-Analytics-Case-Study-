# AquaFizz-Business-Analytics-Case-Study

## Overview

This project analyzes **employee working hours** and **sales performance** for AquaFizz, a health-focused beverage startup. The goal is to ensure workforce compliance and derive actionable business insights using Excel.

## Objectives

* Monitor employee working hours against company policy (8 hrs 30 mins).
* Identify compliant and non-compliant entries with tolerance handling.
* Analyze sales, customers, cities, and beverage profitability.
* Build an interactive Excel dashboard for decision-making.

## Data Used

* Employee Working Hours (Excel)
* Orders.xlsx
* Customers.xlsx

## Key Analysis

* Working hours compliance and deviation calculation
* Profit per sale and monthly profit analysis
* Top customers, cities, and beverages by sales
* Excel dashboard creation

## Tools

* Microsoft Excel
* Formulas, Pivot Tables, Charts, Conditional Formatting

## Outcome

Improved visibility into employee productivity and sales performance, enabling data-driven operational and marketing decisions.
